# 需求范围与数据边界

## 需求一：干湿两用吸尘器

- 榜单：Amazon US Best Sellers，Browse Node `553022`
- 链接：<https://www.amazon.com/gp/bestsellers/hi/553022/ref=pd_zg_hrsr_hi>
- 输出：Top 50、榜单变化、公开价格与规格、评论 VOC、策略建议
- 边界：公开页面的月购买量和推算销售额是估算，不得标记为真实销量

## 需求二：Spot Cleaner

- 榜单：Amazon US Best Sellers，Browse Node `1063922`
- 链接：<https://www.amazon.com/gp/bestsellers/home-garden/1063922/ref=pd_zg_hrsr_home-garden>
- 处理规则：该节点范围宽于 Portable Spot Cleaner，需要排除全尺寸机器、清洁剂和附件
- 专属字段：清水箱、污水箱、软管、加热/蒸汽、自清洁等

## 需求三：全球竞品新品

- 品牌：DEWALT、Milwaukee、Bissell、Hoover、Shark、Greenworks、Ryobi、
  CRAFTSMAN、Kärcher、Dreame、Tineco、Roborock、UWANT、Deerma、Narwal

## 需求四：店铺销售分析

- Vacmaster：全部目标产品
- 链接：<https://www.amazon.com/stores/Vacmaster/page/DFC52640-DE31-4B55-94C5-31A9A71D9BEF>
- Kenmore：仅 Floor Care
- 链接：<https://www.amazon.com/stores/page/E4D32E8D-555F-4F56-B6FB-B14824EC578C>
- 公开 Store ID 仅用于识别页面，不等同于 Seller Central 销售账户授权
- 真实销售分析必须使用 Seller Central Sales & Traffic、Listings/库存和广告报表
- Kenmore 正式分析前应由公司提供 CLEVA 负责 SKU 白名单

## 当前自动化方式

1. Amazon 榜单优先直接采集，失败后上传 CSV/XLSX。
2. 评论使用上传方式，避免大量逐页访问触发验证码。
3. 竞品情报自动搜集后，由用户编辑型号、状态、规格和可信度。
4. 销售数据使用人工导出、系统自动分析；获得 SP-API 后再替换人工上传环节。
5. 所有结果在同一个 Streamlit 应用中保存快照并导出 Excel。
